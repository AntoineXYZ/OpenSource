SystemHits helper, AuAtom13.dll 0x1801b85a0:
Command/control, surgery and individual turrets each have one internal hit.
Maneuver, life support, reactor, sensor, shield and FTL use installed unit counts.
Transporters use pad count for the room key; weapons use units in that bay.
Fuel/hold/vehicle structure hits are floor(hull factor * volume / 256), minimum
one for a nonempty volume. HullHits (AuData13.dll 0x1800733a0) subtracts those
three separately rounded values from total structure hits. Authoring remaining
hits equal maximum hits: no damage state is invented or serialized. Defensive
handling clamps a negative hull remainder and zero-capacity bar to zero.

RenderBodyStats, AuAtom13.dll 0x1804122a0:
Uses DetailSystem's system/which for SystemHitsRemaining/SystemHits. Draws that
ratio, system icon and ship name, without numeric HP or a subsystem-name label.
Filled colors: >=.5 green (.2,1,.2), >.1 amber (1,.7,.2), <=.1 red (1,.2,.2).
Unused color: (.5,.35,.1), or (.5,.1,.1) at critical health. Visible actor
conditions can also force red; the authoring preview has no such conditions.
RenderSystemIcon (AuGL13.dll 0x1800242d0) uses item effect system+0x35. Legacy
system 15 selects the door tile, not modern capacitor. Reuse HudItems.png.

Acquisition, EXE 0x14032f800:
Same detail acquires 0,1,2,4,8,15; changing detail on the same ship adds one
(cap 15), even for the same subsystem. Lost sight halves the level, retaining
detail/health/location until zero. Existing top-down and distance <= 10*level
gates remain. New/rebuilt designs clear the target.

Target name (follow-up recovery):

Name 0x180409000 falls back to the spacecraft atom's AuId::StringId when no
name was assigned; this is not the design title or AuDice::RandomShipName.
DaDesignPlane::Create 0x1802fd060 allocates that atom ID independently of the

AuData13.dll DescStructure 0x1800726d0 calls Structure 0x1801d59c0, then
DnSpaceShip::StructureName 0x180046950: Hull, Starship, Spaceship, Starbase,
Spaceport for 0..4. The existing CalculatePerformance reproduces those rules:
fuel capacity, helm, drive, plant, sufficient life support and an opening or
transporter must exist; otherwise Hull. Multiple maneuver units and >=100ft/s2
TL0 acceleration make a mobile ship. Installed FTL units choose Starship or
Starbase, otherwise Spaceship or Spaceport. This does not use canEngageFTL,
current fuel, capacitor charge or subsystem switches. Modern structure labels
cannot be substituted directly because their station entries have changed.

The preview reuses native AuId::StringId for its registration and shares the
legacy structure-name helper with F6 (which retains Invalid Design for Hull).
The original global ID allocator's seed/sequence was not recovered; a local
random nonreserved ID supplies the preview registration. It is used only for
the HUD/local welcome, never installed as a world atom or saved into the design.
New/Open regenerates it; edits, saves and render toggles preserve it. The HUD
recomputes the class on edits and the welcome uses the unprefixed registration.
