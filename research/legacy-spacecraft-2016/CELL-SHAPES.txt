2016 spacecraft designer: recovered grid-cell geometry
Captured 2026-10-04; all legacy addresses refer to /AuAtom13.dll.

Result and scope
----------------
The original grid toggles combine four families of lines. Eleven combinations
form bounded paint cells: squares, parallelograms, diamonds and triangles. A
cell is not always confined to the square containing the cursor. The shape
and original clockwise vertex order are recovered for every combination.

cell_shapes.py is an executable, standard-library-only reference.
cell-shapes.json contains the table in integer half-grid coordinates.
cell_shapes.py --atlas regenerates an SVG of all masks and cursor sectors.
These artifacts describe GetFillShapeAt, before room painting, room merging,
erasing, detail reconciliation or any deck constraints in its callers. No
native editor behavior is implemented by this recovery artifact.

--------

  0x1802fd130 EnableDiagonal45Lines:  byte at this+0x3b1 |= 0x02.
  0x1802fd150 EnableHorizontalLines: byte at this+0x3b1 |= 0x01.
  0x1802fd170 EnableVerticalLines:   byte at this+0x3b1 |= 0x04.
  0x1802fd090/0b0/0d0/0f0 corresponding disablers clear only their bit.
      No requirement to retain enough enabled families occurs in these setters.
  0x180208070 DoesGridFormBoundaries rejects 0,1,2,4,8 and accepts other bytes.
  0x1802fced0 and 0x1802fcf30 constructors initialize the grid mask to 0x05,
      by storing little-endian 0x0500 at this+0x3b0.
  0x18020edd0 GetGridSpacing returns the fixed constant G = 5.656854249 feet.

Full helpers are stored in pseudocode/AuAtom13.dll_cell_shape_helpers.txt and
pseudocode/AuAtom13.dll_cell_shape_defaults_and_disablers.txt. Assembly is in
pseudocode/AuAtom13.dll_1802fd190_GetFillShapeAt_assembly.txt. Raw constant reads
are retained in cell-shape-constants.json; the source binary is unchanged.

The surviving modern src/lib/atom/entities/design/dadesignplane.h independently
confirms the bit names and values. The old exported setters are the evidence
for their meaning in the 2016 binary. Shape labels such as "east" and "diamond"
below are explanatory geometric labels, not recovered UI names or enum labels.

Coordinates and precision
-------------------------
G = 5.656854249 feet is the full grid spacing; H = G/2 = 2.8284271245 feet.
A full square has approximately 32 square feet. Keep the stored constant;
replacing it with a fresh calculation of sqrt(32) changes the binary64 value.

Referenced literal bit patterns (hexadecimal binary64, before little-endian
storage) are:
  H       0x4006a09e6676c64a = 2.8284271245
  G       0x4016a09e6676c64a = 5.656854249
  1.5 G   0x4020f876ccd914b8 = 8.485281373500001
  2 G     0x4026a09e6676c64a = 11.313708498
Negatives of H and G also occur. Examples of read addresses: G at
0x18073b618, scalar threshold 0.5 at 0x180740c90, H/H at 0x1807972d0,
1.5G/H at 0x1807972e0, and -H/H at 0x18073b770.

Each output vertex is a local XY constant plus (ix*G, iy*G). Its Z is exactly
the input point's Z; this function neither rounds to an 8-foot deck nor checks
deck or ship bounds. Output is an array of three or four vertices without a
duplicate closing vertex. Arrays are clockwise in world XY with Y upward.

Snapping, including the negative-grid seam
-----------------------------------------
First clear the output. Read the grid mask byte at this+0x3b1. Masks 0,1,2,4,8
return immediately. Compute the following independently for X and Y:

    scaled = coordinate / G
    index = trunc_toward_zero(scaled)
    if scaled < 0.0:
        index -= 1
    fraction = scaled - index

This is NOT floor at exact negative integers. The assembly uses CVTTSD2SI
followed by a negative-value test and DEC (0x1802fd222 through 0x1802fd247).
Thus X=-G yields ix=-2 and fx=1, while X=+G yields ix=1 and fx=0. Negative
zero takes ix=0. At ordinary negative nonintegral positions this matches floor.
Keep this quirk for compatibility; do not silently replace it with floor.

The legacy routine converts into signed 32-bit indices. Nonfinite inputs and
out-of-range conversion are outside the reference's supported domain; actual
paint coordinates are bounded by the design environment. The reference raises
ValueError for unsupported active-mask inputs rather than pretending to model
processor-specific invalid-conversion behavior.

Cursor-sector selection and ties
-------------------------------
Let fx=X/G-ix and fy=Y/G-iy. The four sector labels are E=0,N=1,W=2,S=3.
Preserve the exact binary64 operations and comparison order:

    if fx < 0.5:
        if fy <= 0.5:
            sector = 2 + int(0.5 - fx <= 0.5 - fy)
        else:
            sector = 1 + int(fy - 0.5 <= 0.5 - fx)
    elif fy <= 0.5:
        sector = 0 if 0.5 - fy < fx - 0.5 else 3
    else:
        sector = int(fx < fy)

Cardinal interior examples: (.875,.5)->E, (.5,.875)->N,
(.125,.5)->W, (.5,.125)->S. Exact diagonal examples: (.25,.25)->S,
(.25,.75)->W, (.75,.75)->E, (.75,.25)->S. Exact center (.5,.5)->S.
Square corners (0,0),(0,1),(1,1),(1,0) select S,W,E,S respectively.

Do not simplify the lower-left comparison to fx>=fy: rounded subtraction can
change one-ULP cases. For example, moving .25 one representable value toward
zero while holding fy=.25 still selects S because .5-fx rounds to .25. A
second step toward zero selects W. These are preserved by the reference.

Shape table
------------
cell-shapes.json is the canonical table of ordered integer half-grid vertices
for all eleven masks and four cursor sectors. Bits are horizontal=1, D45=2,
vertical=4 and D135=8. Coordinates are relative to (ix*G,iy*G); (1,1) is the
square center. Use cell_shapes.py --table for a readable dump or --atlas for
an SVG. Keep original first vertices and clockwise append order.

Masks 0,1,2,4,8 have no bounded cell and yield no vertices. Every remaining
byte value outside 0..15 also yields no vertices through the switch default,
although DoesGridFormBoundaries returns true for those values. Normal toggles
preserve the four-bit range; the helper does not mask corrupt input to 0x0F.

Reference use and limits
-------------------------
Run from the repository root (no client build):
    python3 -B research/legacy-spacecraft-2016/cell_shapes.py --self-test
    python3 -B research/legacy-spacecraft-2016/cell_shapes.py --table
    python3 -B research/legacy-spacecraft-2016/cell_shapes.py --point 0xF 1 2 24
    python3 -B research/legacy-spacecraft-2016/cell_shapes.py --atlas

The independent oracle intersects enabled line-family half-planes rather than
copying the table. It excludes line ties; explicit assembly-derived fixtures
cover those. TESTING.txt records coverage. The reference is a static recovery,
not a comparison against automated mouse input in the original client. Room
identity, raster mutation and equipment rules are separate specifications.
