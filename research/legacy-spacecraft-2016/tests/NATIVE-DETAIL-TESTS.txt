Native equipment reconciliation validation
-----------------------------------------
This harness is outside game targets. The assistant has not built it.
The user can compile it manually from the repository root:

  c++ -std=c++11 -fPIC -no-pie \
    -Isrc/lib/data/designs \
    research/legacy-spacecraft-2016/tests/native_detail_reconciliation.cpp \
    src/lib/data/designs/aulegacyship.cpp \
    src/lib/data/designs/aulegacyshipdetails.cpp \
    $(pkg-config --cflags --libs Qt5Core Qt5Gui) \
    -o /tmp/native_detail_reconciliation

Then run /tmp/native_detail_reconciliation.

These synthetic fixtures test recovered behavior; they are not original
before/after files. See EQUIPMENT-RECONCILIATION.txt for the evidence and limits.
